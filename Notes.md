Express:
A Node.js web framework used to create APIs and backend servers.

Mongoose:
An ODM (Object Data Modeling) library for MongoDB.
It lets you define schemas and interact with MongoDB using JavaScript objects.

dotenv:
Loads variables from .env file into process.env.

bcryptjs:
Hashes passwords securely.

jsonwebtoken:
Creates and verifies JWT tokens for authentication.

cors:
Allows frontend and backend on different origins to communicate.

nodemon:
Automatically restarts server when files change.

required
Means field must exist.

unique
Creates unique index in MongoDB.

IMPORTANT:
unique is NOT validation logic.
It creates a DB-level uniqueness constraint.
